Accessibility statement

CityDesk is a fictional city portal. This page is a real destination so an agent asking what else the site publishes gets a URL, not a fragment. Software: MIT License.

Service pages: home, parking, libraries, notices.

What we aim for

We target WCAG 2.2 level AA. The service pages are structured with landmarks and a heading outline, and every interactive control carries an accessible name.

Known gaps

The service page deliberately contains a broken-structure zone with no landmark and divs styled as headings, so the SDK's fallback paths can be demonstrated rather than claimed. That zone is not representative of the rest of the site.
